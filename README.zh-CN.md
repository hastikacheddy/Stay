# Stay · 旅行住宿应用

[English](README.md) | 简体中文

> 本科二年级小组作业：一款酒店预订应用。

## 项目目的

本仓库包含 **Stay** 应用的代码。Stay 是一个旅行住宿平台，本次迭代新增了多项功能并改进了原有功能，目标是提升用户体验、简化出行规划，主要面向 Android 用户。

## 简介

Stay 帮助旅行者轻松找到合适的住宿，无论是酒店还是民宿短租。

## 问题背景

旅游业曾是毛里求斯经济的支柱，但面临热门景点过度拥挤、旅行体验千篇一律等问题。新冠疫情进一步放大了这些问题，也凸显了灵活、个性化旅行方案的重要性。Stay 希望打造一个能够根据个人偏好动态调整的平台来应对这些挑战。

## 新增功能

1. **语音登录**：通过语音识别实现便捷的身份验证。
2. **增强安全性**：限制使用语音输入密码，提高登录安全。
3. **语音导航**：通过语音指令在应用内自由跳转。
4. **语音搜索**：用语音快速搜索地点和酒店。
5. **二维码扫描**：扫描二维码即可快速查看酒店信息。
6. **摄像头识别银行卡**：用手机摄像头直接录入银行卡信息，支付更方便。
7. **图片上传识别银行卡**：也可以上传银行卡照片来录入卡片信息。

## 技术栈

- **Flutter / Dart**：跨平台移动应用开发
- **Firebase**：后端服务（身份验证、数据存储等）

## 运行方法

```bash
flutter pub get
flutter run
```

需要预先安装 Flutter SDK 和 Android 开发环境。
